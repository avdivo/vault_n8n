# CHANGELOG

## v1.0.2 - 01.02.2026

### Новые возможности
- Добавлена проверка ключа шифрования при запуске приложения.
- Добавлен форматированный вывод токенов (`VAULT_N8N_AUTH_TOKEN`, `VAULT_N8N_ENCRYPTION_KEY`) в консоль при их генерации.
- Установлено фиксированное имя контейнера (`vault-n8n`).

### Улучшения
- Переименованы переменные окружения `AUTH_TOKEN` и `ENCRYPTION_KEY` на `VAULT_N8N_AUTH_TOKEN` и `VAULT_N8N_ENCRYPTION_KEY` во всем проекте.
- Улучшено обнаружение Python в скриптах запуска.
- Обновлена документация (`README.md`, `.env.example`) с подробными инструкциями по установке, генерации токенов, структуре файлов, интеграции с n8n, использованию API и публикации новых версий.

### Исправления
- Исправлена генерация и отображение токенов в консоли в `start.sh`.
- Добавлена надежная обработка создания файла `secrets.db`.
- Исправлены тесты шифрования после изменения типа исключения.

### Прочее
- Добавлен скрипт для интеграции сервиса в `kossakovsky/n8n-install`.

## v1.0.0 - 29.01.2026

- Первоначальная настройка проекта.
